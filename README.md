# Hogwarts V5 — Editorial Redesign

Интерактивна дигитална биография на Хогуортс. HTML5, CSS3 и Vanilla JavaScript.

## Design direction
Dark academia, restrained gold typography, cinematic photography and a continuous editorial narrative. V5 replaces the sticky four-scene crossfade with native scrolling and images placed at meaningful points in the story. No zoom, custom wand or scroll hijacking.

## Structure
Castle hero → invitation → train and entrance → Great Hall → history → four houses → magical education → sorting ceremony.

All four local WebP images from V4 are reused. House and hat SVG illustrations remain provisional. Golden pointer glitter and the five-question quiz remain. The previous V4 version is preserved in feature/cinematic-design.

## Run
Open index.html directly or run python3 -m http.server 8765.

## University requirements
Headings, paragraphs, internal and external links, semantic table, ordered and unordered lists, images with alt text, CSS column-count, external CSS and optional custom JavaScript.

## Review status
Code-level implementation only; browser testing and visual review of V5 are still required. V4 test results are documented in its branch and are not V5 test results.
