# Hogwarts — Beyond the Castle
Учебен проект по HTML, CSS и JavaScript. Отворете index.html в браузър. Не е необходим интернет за основната страница.

## Файлове
- index.html — съдържание и семантични HTML елементи
- style.css — оформление, адаптивност, многоколонен текст
- script.js — прогрес, scroll zoom, избор на дом
- assets/ — оригинални стилизирани SVG илюстрации

## Изисквания
h1/h2/h3, p, a, table, ul/ol, img, CSS column-count, външен CSS и собствен JavaScript. JavaScript е по избор; не е копиран от FreeFrontend.

Вдъхновение: https://github.com/Meghamittal0920/itachi . Самостоятелна реализация, без копирани файлове. Неофициална учебна фен страница за измисления свят на Harry Potter.

## Версия 2
Интерактивно писмо, sticky секция с увеличение според скрола, CSS мъгла и магически частици. Илюстрацията е SVG, не поредица от видеокадри.

## Публикуване
Settings → Pages → Deploy from a branch → main → / (root) → Save.
